BudgetZen V1 — application web installable sur iPhone

Contenu : index.html, app.js, sw.js, manifest.webmanifest, icon.svg.

Publication gratuite possible : créer un dépôt GitHub public, ajouter les cinq fichiers à la racine, activer Settings > Pages > Deploy from a branch > main / (root). Attendre l'URL HTTPS fournie par GitHub Pages.

Sur iPhone : ouvrir l'URL HTTPS dans Safari, toucher Partager > Sur l'écran d'accueil > Ajouter.

Attention : les données sont stockées localement sur l'appareil et le navigateur. Exporter une sauvegarde JSON régulièrement. Aucune synchronisation entre appareils, aucune connexion bancaire, aucun paiement intégré. Pour commercialiser l'app, il faudra ajouter une authentification, une gestion des abonnements et des conditions/confidentialité adaptées.
